============================================================
 Satisfactory Splunk Exporter - Installation (v2.0)
============================================================

This is a C++ SML mod. It cannot be installed by copying source
files into the game - it must be COMPILED once with the official
Satisfactory modding toolchain, then packaged with Alpakit.

STEP 1 - Build the mod
----------------------
Follow the official SML development setup guide:
  https://docs.ficsit.app/satisfactory-modding/latest/Development/BeginnersGuide/index.html

Summary:
  1. Install Visual Studio 2022 (C++ game dev workload) and Wwise.
  2. git clone https://github.com/satisfactorymodding/SatisfactoryModLoader.git
  3. Install the custom engine (Unreal Engine - CSS) per the guide.
  4. Copy this repository to:
       SatisfactoryModLoader/Mods/SatisfactorySplunkMod/
     (the folder that contains SatisfactorySplunkMod.uplugin)
  5. Generate VS project files for FactoryGame.uproject, build the
     "Development Editor" target.
  6. Open the editor, Window -> Alpakit, select SatisfactorySplunkMod,
     click "Alpakit!". It packages the mod and copies it into your
     game's FactoryGame/Mods/ folder.

STEP 2 - Set up Splunk HEC
--------------------------
  1. Splunk: Settings -> Data Inputs -> HTTP Event Collector -> New Token.
     Choose/create an events index (e.g. "satisfactory"). Copy the token.
  2. IMPORTANT: the default HEC SSL certificate is self-signed and the
     game will reject it. On a LAN, disable SSL in HEC Global Settings
     and use http://your-server:8088/services/collector/event
  3. Verify with curl from the gaming machine:
       curl http://your-splunk:8088/services/collector/event \
         -H "Authorization: Splunk YOUR-TOKEN" -d '{"event":"test"}'
     Expected: {"text":"Success","code":0}

STEP 3 - Configure the mod
--------------------------
Edit, inside the INSTALLED mod folder:
  <game>/FactoryGame/Mods/SatisfactorySplunkMod/Config/SatisfactorySplunkMod.ini

Set:
  SplunkURL=http://your-splunk:8088/services/collector/event
  HECToken=<your token>

(Or set env vars SPLUNK_HEC_URL / SPLUNK_HEC_TOKEN - useful for
dedicated servers. They override the ini.)

STEP 4 - Verify
---------------
Start the game, load a save, then check:
  <game>/FactoryGame/Saved/Logs/FactoryGame.log
Look for:
  LogSatisfactorySplunkMod: SplunkGameWorldModule: SplunkExporter spawned
  LogSatisfactorySplunkMod: SplunkExporter: collection started (...)
  LogSatisfactorySplunkMod: SplunkExporter: HTTP 200 - 1 batches ...

In Splunk:
  index=satisfactory | head 10

See README.md for the full list of sourcetypes, example searches,
and troubleshooting.
